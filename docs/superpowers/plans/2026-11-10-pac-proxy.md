# PAC Proxy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Faire fonctionner OpenRouter derrière un proxy PAC dans le GUI, sans régression pour les proxys classiques ni le CLI.

**Architecture:** Le GUI résout le PAC via `QNetworkProxyFactory` uniquement quand `urllib.request.getproxies()` est vide. Le proxy résolu est injecté dans `OpenRouterEngine`, qui construit un `ProxyHandler` `urllib`. Le CLI et les configurations classiques gardent `urllib.request.urlopen` par défaut.

**Tech Stack:** Python 3.13, PySide6 (QtNetwork), urllib.

**Spec:** `docs/superpowers/specs/2026-11-10-pac-proxy-design.md`

## Global Constraints

- Aucune nouvelle dépendance.
- Ne pas modifier le comportement du CLI.
- Les variables d'environnement et la configuration système classique doivent conserver leur comportement actuel.
- Toute correction commence par un test qui échoue.

## Review Focus

- Un proxy classique (variable d'environnement ou registre) doit continuer à être utilisé par défaut.
- Un PAC doit être résolu sans écraser les variables d'environnement.
- Un PAC inaccessible ou un proxy `NoProxy` ne doit pas casser le moteur.
- Le proxy ne doit pas être journalisé (pas de fuite de configuration réseau).
- L'opener par défaut doit rester utilisé quand aucun proxy n'est fourni.

```python
"""Résolution du proxy système, y compris PAC, pour les moteurs du cœur."""

from __future__ import annotations

import urllib.request

from PySide6.QtCore import QUrl
from PySide6.QtNetwork import QNetworkProxy, QNetworkProxyFactory, QNetworkProxyQuery

_HTTP_TYPES = {
    QNetworkProxy.ProxyType.HttpProxy,
    QNetworkProxy.ProxyType.HttpsProxy,
}
_SOCKS_TYPES = {
    QNetworkProxy.ProxyType.Socks5Proxy,
}


def resolve_proxy_for(url: str) -> str | None:
    """Retourne un proxy utilisable par urllib, ou None pour le défaut."""
    if urllib.request.getproxies():
        return None
    try:
        proxies = QNetworkProxyFactory.systemProxyForQuery(
            QNetworkProxyQuery(QUrl(url))
        )
    except Exception:
        return None
    for proxy in proxies:
        if proxy.type() in _HTTP_TYPES:
            return f"http://{proxy.hostName()}:{proxy.port()}"
        if proxy.type() in _SOCKS_TYPES:
            return f"socks5://{proxy.hostName()}:{proxy.port()}"
    return None
```
